## 1. Введение

Кластер B12 представляет собой малый нейтральный борный кластер из 12 атомов бора. Для таких систем устойчивость и относительная энергия сильно зависят от геометрии, спинового состояния и исходной конфигурации, из которой начинается оптимизация.

Поиск устойчивой геометрии проводится для того, чтобы найти стационарные структуры на поверхности потенциальной энергии и отобрать среди них наиболее низкоэнергетические кандидаты. Сравнение только одной стартовой структуры недостаточно, потому что разные начальные конфигурации могут оптимизироваться как в один и тот же минимум, так и в разные локальные минимумы.

Для B12 особенно важно рассматривать не только 3D-кандидаты, но также планарные и квазипланарные мотивы. В литературе малые борные кластеры часто имеют плоские или почти плоские низкоэнергетические формы, поэтому предварительный 3D-минимум нельзя автоматически считать глобальным минимумом без контроля таких структур.

## 3. Методика

Для нейтрального B12 были подготовлены разные стартовые геометрии:

- `bilayer_3d`
- `compact_3d`
- `icosahedron`
- `distorted_cage`
- `distorted_icosahedron_01`, `distorted_icosahedron_02`
- `random_3d_01`, `random_3d_02`, `random_3d_03`
- `planar_double_ring`
- `planar_triangular_patch`
- `quasi_planar_buckled_double_ring`

Для каждой стартовой геометрии перебирались начальные расстояния:

`d = 2.0, 2.5, 3.0, 3.5, 4.0, 4.5, 5.0 A`

Для каждого значения `d` рассматривались мультиплетности:

`M = 1, 3, 5`

Расчеты выполнялись на уровне `PBE0-D3BJ/def2-SVP` в режиме `Opt Freq`. Оптимизация использовалась для получения стационарной геометрии, а частотный расчет - для проверки, является ли найденная структура истинным минимумом.

## 4. Критерий выбора лучшей структуры

Лучшая структура выбиралась не по стартовой геометрии, а по результатам оптимизации и частотного анализа.

Критерии истинного минимума:

1. `ORCA TERMINATED NORMALLY`
2. SCF сошелся
3. мнимые частоты отсутствуют
4. для нелинейного B12 найдено 30 нормальных колебательных мод
5. полная энергия минимальна среди корректно завершенных истинных минимумов

Такой критерий исключает структуры, у которых оптимизация завершилась, но отсутствует полноценная частотная проверка или найдено неправильное число колебательных мод.

## 6. Частотный анализ лучшего кандидата

Для структуры `bilayer_3d/d_3.5/mult_1` проведен частотный анализ. Получено 30 нормальных колебательных мод B12. Все частоты положительные, мнимые частоты отсутствуют.

| Параметр | Значение |
|---|---|
| Диапазон частот | 193.27-1358.99 cm^-1 |
| Минимальная частота | 193.27 cm^-1 |
| Максимальная частота | 1358.99 cm^-1 |
| Мнимые частоты | отсутствуют |

Отсутствие мнимых частот подтверждает, что найденная структура является истинным минимумом на выбранном уровне теории `PBE0-D3BJ/def2-SVP`.

## 7. Ограничения

Полученный результат является предварительным. На данном этапе структура `bilayer_3d/d_3.5/mult_1` является лучшим найденным минимумом среди обработанных расчетов, но не окончательным глобальным минимумом B12.

Для окончательного вывода необходимо:

1. завершить расчеты планарных и квазипланарных контрольных структур;
2. выполнить финальное уточнение лучшей структуры на уровне `PBE0-D3BJ/def2-TZVP Opt Freq`;
3. сравнить энергии всех истинных минимумов на одинаковом уровне теории.

В текущем workflow планарные и квазипланарные input-файлы уже подготовлены, но их результаты должны быть обработаны перед финальным научным выводом.

## 8. Вывод

В результате предварительного скрининга структур нейтрального кластера B12 на уровне `PBE0-D3BJ/def2-SVP` наиболее устойчивым среди обработанных кандидатов оказался singlet-изомер `bilayer_3d`, полученный из стартовой геометрии с `d = 3.5 A`. Его полная энергия составляет `-297.373546508462 Eh`.

Частотный анализ показал отсутствие мнимых частот и наличие 30 нормальных колебательных мод, что подтверждает принадлежность структуры к истинным минимумам. Окончательный вывод о глобальной устойчивости требует расчета планарных/квазипланарных контролей и финального уточнения на уровне `PBE0-D3BJ/def2-TZVP`.
